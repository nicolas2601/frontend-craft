# Notice: upstream attribution for the frontend-craft agents

The frontend-craft specialist agents in `agents/frontend-craft/` are informed by roles from the design, frontend and testing divisions of the **agency-agents** project.

- Upstream repository: https://github.com/msitarzewski/agency-agents
- Pinned commit: `b37b5bb33b78f2c1d6567d98e25ca818e3259219`
- Upstream license: MIT (text reproduced below, fetched from the pinned commit's `LICENSE` file)

## What is and is not imported

- The `fc-*` files are **original adaptations** written for the frontend-craft stages (see `skills/frontend-craft/references/agent-roster.md`). They are not copies of the upstream files.
- Upstream persona text, emoji styling, memory sections and integrations were **not** copied.
- The **whole upstream agency is not imported.** Only the ideas listed below informed ten narrow roles. Other upstream agents are not part of this repository.
